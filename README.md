# MHFileManager - Administrador de archivos MHenriquez 🗃️

Proyecto para gestionar el progreso de desarrollo en una carpeta dev hacia una carpeta drive sincronizada, para no tener conflictos por archivos abiertos, se creó esta interfaz para automatizar el proceso de copiado y pegado al terminar un desarrollo.
